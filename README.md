# Jeu du Pendu (Hangman)

Une application web simple du célèbre **jeu du pendu**, développée en **JavaScript**, permettant aux joueurs de deviner un mot lettre par lettre avant que le dessin du pendu ne soit complété.

## Description

Le jeu du pendu est un jeu de devinette où le joueur doit trouver un mot caché en proposant des lettres.  
À chaque mauvaise lettre proposée, une partie du pendu est dessinée.  
Le joueur gagne s'il découvre le mot avant que le dessin soit terminé.

## Fonctionnalités

- Génération aléatoire d'un mot à deviner
- Saisie des lettres par clavier ou boutons
- Comptage des erreurs
- Affichage progressif du pendu
- Détection automatique de victoire ou de défaite
- Possibilité de recommencer une partie
- Interface simple et interactive
- Ajouter plusieurs catégories de mots
- Ajouter un mode multijoueur
- Ajouter des animations
- Ajouter un système de score
- Sauvegarder les parties
- Dessiner le pendu en SVG
- Sons
- Responsive

## Technologies utilisées

- **HTML5** – structure de la page
- **CSS3** – mise en forme de l'interface
- **JavaScript (Vanilla JS)** – logique du jeu et interactions
